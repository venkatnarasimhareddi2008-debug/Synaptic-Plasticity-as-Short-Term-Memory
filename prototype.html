For: ML practitioners comfortable with linear algebra and basic neural-network concepts. No prior knowledge of Hopfield networks or BDH required. Objective: Understand Hebbian plasticity, the η–λ–θ trade-off, and how this foundational mechanism appears in the Dragon Hatchling (BDH) architecture.
A recurrent network with Hebbian synapses can store and retrieve multiple patterns from partial cues, but the trade-off between learning rate (η) and decay (λ) creates a sharp failure boundary, not a smooth gradient, because thresholding (θ) amplifies the effect of synaptic loss.

1. Flash, store and forget

The core Hebbian learning rule [Hebb, 1949] - "neurons that fire together, wire together" -- is formalised as the outer-product update. When a pattern is presented, every pair of co-active neurons increases its synaptic weight by the learning rate η. For active cells i and j, the update is: Δwij = η · xi · xj where xi ∈ {0,1} is the activation of neuron i. This is a local, biologically plausible rule: only synapses connecting two simultaneously active neurons are strengthened, requiring no global error signal. This is the foundational mechanism for associative memory. The network stores three distinct patterns (T, +, L) sequentially. Each store adds a rank-one outer-product matrix to the weight matrix W. Between stores, synaptic decay multiplies every weight by (1 - λ) each tick. The trace of a memory after age t is (1 - λ)t -- the fraction of the original weight that remains.

Recall is iterative: starting from a damaged cue, each neuron computes its total input current hi = Σj≠i Wij xj, then updates to 1 if hi > θ, to 0 if hi < θ, or stays unchanged if equal. This is a thresholded linear dynamical system that converges to an attractor corresponding to one of the stored patterns. 2. Hebbian write vs gradient-descent training

This comparison contrasts local, biologically inspired plasticity with global, error-driven optimisation. The Hebbian network performs a single outer-product update on the pattern T (13 active cells in a 7×7 grid). This strengthens exactly k(k−1) = 13×12 = 156 synapses -- a sparse, instantaneous, local write. The gradient-descent network, in contrast, treats the network as a linear autoencoder that must reproduce the input from its own output. For each neuron i, the output is: ŷi = Σj Wij xj The loss is the mean squared error: L = (1/N) Σi (xi − ŷi)2 The delta-rule update is ΔWij = ηGD (xi − ŷi) xj, adjusting all 49×49 = 2401 weights each epoch. This comparison illuminates the fundamental trade-off between memory and generalisation. Hebbian learning is extremely efficient for rapid memorisation but lacks generalisation capacity; gradient descent is slower but can interpolate and generalise to unseen inputs. Running 50 GD epochs reduces the loss to near zero, but at the cost of dense computation over many steps.

3. Decay, threshold and the energy landscape

The interaction between decay rate λ and threshold θ is central to understanding the phase transition in associative memory. As time passes, all weights are multiplied by (1 - λ) each tick, producing exponential decay: Wij(t) = Wij(0) · (1 - λ)t This trace strength decreases smoothly and continuously. However, recall success does not follow this smooth decline. The recall accuracy (fraction of the original pattern's active cells recovered) stays high for a long time, then drops precipitously. The threshold θ introduces a nonlinearity that amplifies small synaptic losses. As long as hi > θ for all critical neurons, the pattern is perfectly reconstructed. But once even one critical neuron's input falls below θ, that neuron fails to fire, and the entire pattern collapses -- the network falls into a different attractor. This is a phase transition: a continuous change in weights produces a discontinuous change in recall outcome.

4. Memory blender: two patterns collide

Interference in associative memory occurs when two patterns are stored in the same weight matrix. Their contributions add linearly: W = WA + WB where WA is the outer-product matrix for pattern A and WB for pattern B. Each pattern contributes η · (1 - λ)age to its synapses, scaled by its age. The older pattern has been decaying for longer, so its weights are reduced by (1 - λ)Δage relative to the newer pattern. When you recall the older pattern, the network's total input includes contributions from both stored patterns, creating cross-talk. Synapses shared between the two patterns receive contributions from both -- which can be beneficial if they align or harmful if they conflict. The difference map shows connection dominance: red synapses are dominated by the older pattern, blue by the newer, and purple by both. Adjusting the age difference changes the relative strength of the two memories. At small age differences, both patterns are strong; at large differences, the newer pattern dominates, and the older pattern becomes increasingly corrupted. This demonstrates the capacity limits of associative memory: with N neurons, a Hopfield network [Hopfield, 1982] can store approximately 0.138 × N orthogonal patterns before interference causes catastrophic forgetting [Amit et al., 1985]. Recent work by [Millidge et al., 2024] extends this classical Hopfield framework to a broader class of single-shot associative memory paradigms, providing a unified theoretical perspective on energy-based memory models.

5. The Dragon Hatchling (BDH) synapse model

The Dragon Hatchling (BDH) architecture [Pathway, 2025] is a brain-inspired post-Transformer model where reasoning and memory share one computational fabric. At its core is a fast synaptic state that updates with each input token -- a fast-weight memory [Ba et al., 2016; Schlag et al., 2021]. The update rule, derived from the "From Attention to Synapses" formalism, is: bij(t) = γ · bij(t−1) + xi(t) · xj(t) where bij is the fast synaptic state between neurons i and j, γ is a retention factor (analogous to 1 - λ), and xi(t) xj(t) is the Hebbian outer-product of the current activation vector. This is the same mathematical form as our toy network's update, but BDH implements it at billions of parameters with GPU-optimised linear attention and ReLU-low-rank transformations. The key innovation is coupling: the fast state is updated during every recall (inference) step, not just during explicit storage. This allows the network to learn from context and perform demonstration-based reasoning, as shown in BDH-CQ [Pathway, 2026].

The bridge from classical Hopfield networks to BDH's linear attention is the outer-product update. In Hopfield networks, the weight matrix is a sum of outer products: W = Σμ ξμ ξμT. BDH generalises this to sequences: bt = γ bt−1 + kt vtT, where kt and vt are key and value vectors derived from the input. The sparsity slider below controls the fraction of non-negative activations -- BDH reportedly uses approximately 5% sparsity [Pathway, 2025, Table 2], which prevents cross-talk and improves memory fidelity.   • Sparse non-negative activations: approximately 5% of neurons are active at any time [Pathway, 2025, Table 2].
  • Monosemantic synapses: individual synapses encode recognisable semantic concepts [Pathway, 2025, Section 4.1].
  • Scale-free connectivity: trained BDH models exhibit a power-law degree distribution [Pathway, 2025, Fig. 5].

7. Parameter-based tasks

These tasks require you to use the model interactively to discover answers, demonstrating active learning rather than passive consumption. Task A asks you to find a decay rate λ that causes the first failure near t = 30. Task B diagnoses whether a failed recall is due to cue damage, decay, or interference -- a causal attribution task. Task C tests a theoretical limitation: with only three active cells and θ = 3, a missing cell cannot receive enough input to cross the threshold. These tasks transform the tool from a passive demonstration into an active learning environment, directly testing the falsifiable claim that the η–λ–θ trade-off creates sharp failure boundaries.

Common misconception: "More decay always means gradual forgetting."
This is false for thresholded recurrent networks. As shown in Section 3, the trace decays smoothly (exponentially), but recall fails abruptly when the input to any critical neuron falls below θ. The threshold amplifies small synaptic losses into complete pattern collapse -- a phase transition rather than a gradual fade.
Limitations of this interactive model: 49 neurons vs. BDH's billions; simple threshold (McCulloch-Pitts) vs. BDH's ReLU-low-rank dynamics; no pretraining or gradient optimisation; short sequences only; all results are computed live in your browser and illustrate the mechanism, not official BDH benchmarks.
